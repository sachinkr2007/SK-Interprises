## 🚀 Quick Deployment Guide

### Option 1: Deploy with Vercel (Recommended ⚡ 1-Click)
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **"Add New Project"** and import `sachinkr2007/SK-Interprises`.
3. Click **"Deploy"**. Vercel will automatically build and assign a free live URL (e.g., `https://sk-enterprises.vercel.app`).

### Option 2: Deploy with Netlify
1. Go to [netlify.com](https://netlify.com) and click **"Add new site" ➔ "Import an existing project"**.
2. Select GitHub and choose `sachinkr2007/SK-Interprises`.
3. Set build command: `npm run build` and publish directory: `dist`.
4. Click **"Deploy Site"**.

### Option 3: GitHub Pages (Automatic via GitHub Actions)
1. Go to your repository on GitHub: `https://github.com/sachinkr2007/SK-Interprises`.
2. Go to **Settings** ➔ **Pages**.
3. Under **Build and deployment** ➔ **Source**, select **"GitHub Actions"**.
4. Push to `main` and your site will be live at `https://sachinkr2007.github.io/SK-Interprises/`.
